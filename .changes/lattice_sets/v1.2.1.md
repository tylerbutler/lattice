## v1.2.1 - 2026-11-18

### Fixed

#### Preserve observed removals when merging sets with pruned live tags
#### Validate causal metadata when loading legacy ORSets

String v1/v2 decoding now rejects empty live tag sets, invalid counters, duplicate live identities, live/tombstone overlap, and invalid pruning metadata. Loading raises the allocation counter to cover retained tags and pruning history, preventing tag reuse and loss of unrelated elements. Existing wire formats, including optional v1 tombstones, are unchanged; loading cannot recover history that an older writer discarded.
