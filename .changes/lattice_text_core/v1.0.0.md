## v1.0.0 - 2026-07-07


### MajorRelease

#### Stable 1.0 release with a committed public API

`lattice_text_core` is now 1.0. Its backend-agnostic grapheme and range helpers — `RangeError`/`validate_range`, `value`, `slice`, and the generic `insert_graphemes`/`delete_graphemes` fold helpers shared by `lattice_text` and `lattice_text_fugue` — are stable and safe to depend on. From this release on, the package follows semantic versioning, so any future breaking change will come with a new major version.


### Added

#### Add backend-agnostic text-core helpers package

Introduces `lattice_text_core/grapheme` with `RangeError`/`validate_range`, `value`, `slice`, and generic `insert_graphemes`/`delete_graphemes` fold helpers parameterized over a sequence backend's insert/delete/merge. Shared by `lattice_text` and `lattice_text_fugue` so the grapheme/range layer lives in one place.


### Changed

#### `insert_graphemes` now takes a batched `insert_many` backend closure

The generic helper accepts a single `insert_many(state, index, graphemes)` callback instead of a per-grapheme `insert` plus a `merge`, so backends splice a whole run in one operation.
